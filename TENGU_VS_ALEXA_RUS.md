# Tengu Cluster vs Amazon Alexa — В чём разница?

> Почему Tengu — это не «ещё одна Алекса», а принципиально другой инструмент

---

## 🎯 Главное отличие в одном предложении

**Alexa** — это голосовой помощник от Amazon, который выполняет простые команды и продаёт вам сервисы Amazon.

**Tengu** — это ваш личный AI-агент, который живёт на вашем компьютере, понимает контекст вашего бизнеса и может работать с файлами, кодом и данными.

## 🔍 Детальные отличия

### 1. 🧠 Интеллект

**Alexa** понимает простые команды:
```
«Алекса, какая погода?»
«Алекса, включи музыку»
«Алекса, поставь таймер на 10 минут»
«Алекса, закажи туалетную бумагу»
```

**Tengu** ведёт полноценный диалог с контекстом:
```
Вы:     Проанализируй продажи за январь, 
        сравни с прошлым годом и скажи, 
        какие позиции просели и почему

Tengu:  📊 Анализ продаж (январь 2026 vs 2025):
        
        Общая выручка: 12.4M ₸ (+8%)
        
        📉 Просевшие позиции:
        1. Ремни приводные: -23%
           Причина: конкурент «АвтоМир» снизил 
           цены на 15% в декабре
        2. Фильтры воздушные: -12%
           Причина: сезонный спад (зима, 
           меньше замен)
        
        📈 Выросшие:
        1. Подшипники: +34%
           Причина: крупный заказ от ТОО «Агро»
        ...
        
        💡 Рекомендация: снизить цену на ремни 
        на 10% и запустить акцию для удержания 
        клиентов.
```

> **Вывод:** Alexa — это «умная колонка». Tengu — это «умный сотрудник».

### 2. 🔒 Приватность и данные

#### Amazon Alexa:
- 🔴 **Всегда слушает** — ждёт слово-активатор, но записывает фрагменты
- 🔴 **Данные в облаке Amazon** — ваши запросы хранятся на серверах AWS
- 🔴 **Amazon анализирует** ваши привычки для рекламы
- 🔴 **Сотрудники Amazon** могут прослушивать записи (подтверждено)
- 🔴 **Правительство может запросить** данные у Amazon

#### Tengu Cluster:
- 🟢 **Не слушает** — только читает сообщения, которые вы отправляете
- 🟢 **Все данные на вашем диске** — обычные файлы, которые вы контролируете
- 🟢 **Никакой рекламы** — open-source, нет коммерческой модели
- 🟢 **Только вы видите** историю разговоров
- 🟢 **С Ollama** — даже запросы к AI не уходят в интернет

```
Пример: Саня из Караганды ведёт учёт авансов 
водителей через Tengu.

С Alexa: зарплатные данные ушли бы на серверы 
Amazon в США.

С Tengu: данные лежат в файле 
~/tengu/logistics/salary/february.md 
на компьютере в офисе Сани.
```

### 4. 🌍 Экосистема и привязка

#### Alexa — привязка к Amazon:
- Покупает через Amazon → комиссия Amazon
- Музыка через Amazon Music → подписка Amazon
- Умный дом → устройства Amazon (Ring, Blink)
- Хранение → AWS
- **Вы — продукт.** Amazon зарабатывает на ваших данных и покупках.

#### Tengu — свобода выбора:
- AI-модель → любая (Claude, GPT, Llama, Mistral, DeepSeek)
- Мессенджер → любой (Telegram, Discord, CLI)
- Железо → любое (от Raspberry Pi до GPU-сервера)
- Хранение → ваш диск
- **Вы — владелец.** Tengu зарабатывает... ничего. Это open-source.

## � А что с приватностью при использовании API?

> **Важный вопрос:** Если мы используем Claude Opus 4.5 через API — данные ведь уходят на серверы Anthropic? Значит, это не совсем «локально»?

### Честный ответ: да, данные передаются. Но это НЕ то же самое, что Alexa.

---

### 🔄 Как движутся данные

```
┌─────────────┐     ┌─────────────────┐     ┌──────────────┐
│  Вы пишете  │ ──► │  Tengu на вашем  │ ──► │ Anthropic    │
│  в Telegram  │     │  компьютере      │     │ API (облако) │
└─────────────┘     └─────────────────┘     └──────┬───────┘
                           ▲                        │
                           │    Ответ модели        │
                           └────────────────────────┘
```

1. **Вы** отправляете сообщение в Telegram
2. **Tengu** (на вашем компьютере) получает его и формирует запрос
3. **Запрос уходит** на серверы Anthropic для обработки
4. **Ответ возвращается** в Tengu → вам в Telegram
5. **История сохраняется** на вашем диске, не в облаке

### 📜 Политика Anthropic по API

Anthropic **официально гарантирует** для API-клиентов:

- ✅ Данные **НЕ используются** для обучения моделей
- ✅ Данные **НЕ продаются** третьим лицам
- ✅ Данные хранятся **максимум 30 дней** для мониторинга безопасности, затем удаляются
- ✅ Сотрудники **не просматривают** ваши диалоги (если нет нарушения правил)
- ✅ Данные передаются по **зашифрованному каналу** (TLS)

> Это принципиально отличается от ChatGPT через сайт, где ваши диалоги **по умолчанию** используются для обучения. В API такого нет.

### 🛡️ Что контролирует Tengu

Даже при использовании API, Tengu даёт вам защиту:

**1. Изоляция агентов**
```
Агент «Тимур» (сын) НЕ видит данные агента «Ержан» (бизнес).
Даже если оба используют Claude API — в запросы 
Тимура НИКОГДА не попадут бизнес-файлы Ержана.
```

**2. Контроль контекста**
```
Tengu отправляет в API ТОЛЬКО то, что нужно для ответа:
• Ваше сообщение
• Релевантные файлы из workspace агента
• Историю текущего разговора

Файлы за пределами workspace — никогда.
```

**3. Прозрачность**
```
Вы видите: сколько токенов отправлено, 
сколько это стоило, какой контекст был передан.
Никаких скрытых отправок.
```

### 🎯 Гибридная стратегия: что локально, что через API

**Лучший подход — комбинировать:**

| Данные | Движок | Почему |
|--------|--------|--------|
| 💼 Зарплаты, авансы, маржа | `ollama` (локально) | Финансы — никуда не уходят |
| 💼 Контракты, цены поставщиков | `ollama` (локально) | Коммерческая тайна |
| 👶 Домашние задания Тимура | `ollama` (локально) | Бесплатно + безопасно |
| 📊 Аналитика продаж (общая) | `anthropic` API | Нужно качество, данные не критичны |
| ✍️ Контент для блога | `anthropic` API | Не чувствительно, нужен стиль |
| 📝 Подготовка уроков | `anthropic` API | Не чувствительно, нужно качество |
| 🚛 Маршруты и диспетчеризация | `anthropic` API | Общая логистика, нечувствительно |
| 🚛 Штрафы, расход топлива | `ollama` (локально) | Данные сотрудников |

### ⚙️ Как это настроить в Tengu

```toml
# ══════════════════════════════════════════
# Чувствительные данные → ЛОКАЛЬНО (Ollama)
# Ничего не уходит в интернет
# ══════════════════════════════════════════

[agents.erzhan-finance]
engine = "ollama"
model = "llama3.1:70b"
workspace = "~/tengu/business/finance"
# Зарплаты, маржа, авансы — всё локально

[agents.sanya-salary]
engine = "ollama"
model = "llama3.1:70b"  
workspace = "~/tengu/logistics/salary"
# Данные водителей — только на вашем диске

[agents.timur]
engine = "ollama"
model = "llama3.1:8b"
workspace = "~/tengu/timur"
# Бесплатно и безопасно для ребёнка

# ══════════════════════════════════════════
# Общие задачи → API (лучшее качество)
# Данные передаются, но не хранятся и 
# не используются для обучения
# ══════════════════════════════════════════

[agents.erzhan-analytics]
engine = "anthropic"
model = "claude-opus-4-5-20250929"
workspace = "~/tengu/business/analytics"
# Общая аналитика — не содержит секретов

[agents.aigul]
engine = "anthropic"
model = "claude-sonnet-4-5-20250929"
workspace = "~/tengu/aigul"
# Уроки и быт — нечувствительные данные

[agents.dana-blog]
engine = "anthropic"
model = "claude-sonnet-4-5-20250929"
workspace = "~/tengu/blog"
# Контент — публичный по определению
```

### 🔑 Простое правило

> **Спросите себя:** «Если бы этот файл попал в интернет — это было бы проблемой?»
> 
> - **Да** → используйте `ollama` (локально)
> - **Нет** → можно `anthropic` API (лучшее качество)
> 
> Tengu позволяет сделать этот выбор **для каждого агента отдельно**. Ни Alexa, ни ChatGPT такой гибкости не дают.
