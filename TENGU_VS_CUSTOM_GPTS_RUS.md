# Tengu Cluster vs Custom GPTs (OpenAI) — В чём разница?

> Почему Tengu — это не «ещё один кастомный GPT», а принципиально другой подход к AI-ассистентам

---

## 🎯 Главное отличие в одном предложении

**Custom GPTs** — это настроенный чат-бот внутри платформы OpenAI, ограниченный песочницей ChatGPT.

**Tengu** — это AI-агент на вашем компьютере, который имеет доступ к вашим файлам, инструментам и может выполнять реальные действия.

## 🔍 Детальные отличия

### 1. 🧠 «Знание» вашего бизнеса

#### Custom GPTs — загрузка файлов в песочницу:
```
Вы создаёте Custom GPT и загружаете файлы:
• Максимум ~20 файлов
• Файлы существуют ТОЛЬКО в рамках ChatGPT
• При каждой сессии GPT «перечитывает» их
• Нет синхронизации — обновили файл? Загрузите заново
• Файлы в проприетарном хранилище OpenAI
```

#### Tengu — прямой доступ к вашим данным:
```
Tengu работает с вашими реальными файлами:
• Неограниченное количество файлов
• Файлы — обычные .md, .csv, .txt на вашем диске
• Изменения подхватываются мгновенно
• Вы можете редактировать их в любом редакторе
• Индексация через knowledge store
```

**Пример для Сани (логистика):**

```
Custom GPT:
• Нужно вручную экспортировать данные из тетрадки
• Загрузить Excel-файл в ChatGPT
• Если данные изменились — загрузить заново
• GPT забывает всё между сессиями

Tengu:
• Саня пишет: «Дал Серику 30 тысяч аванс»
• Tengu сам записывает в ~/tengu/logistics/salary/february.md
• В следующий раз — уже знает, без повторной загрузки
• Данные копятся, анализируются, никуда не пропадают
```

### 2. 🔧 Действия vs Только текст

#### Custom GPTs — могут только говорить:
```
Вы:     Создай счёт для ТОО «Курылыс» 
        на 85,000 ₸ за доставку

GPT:    Вот шаблон счёта:
        [красиво оформленный текст]
        
        Скопируйте и вставьте в Word.
```
GPT **написал текст**. Дальше — ваша работа.

#### Tengu — может действовать:
```
Вы:     Создай счёт для ТОО «Курылыс» 
        на 85,000 ₸ за доставку

Tengu:  ✅ Счёт создан:
        📄 ~/tengu/logistics/invoices/2026-02-16-kurylys.md
        
        Номер: INV-2026-0089
        Заказчик: ТОО «Курылыс»
        Сумма: 85,000 ₸
        
        Файл сохранён. Отправить клиенту в Telegram?
```
Tengu **создал файл**, **сохранил** и **предлагает отправить**.

### 3. 📱 Платформа общения

#### Custom GPTs:
- Только через chat.openai.com или приложение ChatGPT
- Нужно открыть браузер → войти в аккаунт → найти нужный GPT → написать
- На телефоне — приложение ChatGPT (отдельная установка)
- Нельзя написать из Telegram, WhatsApp, Discord

#### Tengu:
```
Саня в Telegram:
[🎤]: «Серик выехал в Астану, 20 тонн, 
стройматериалы для Курылыса»

Tengu отвечает прямо в Telegram ✅
```

- Работает через **Telegram** — приложение, которое уже стоит на телефоне
- Не нужно открывать браузер, логиниться, искать нужного бота
- Голосовые сообщения → Tengu понимает
- Можно общаться за рулём (голосом через Telegram)

### 4. 👨‍👩‍👦 Мультипользовательский режим

#### Custom GPTs — один пользователь:
```
• Подписка ChatGPT Plus: $20/мес на ОДНОГО человека
• Семья из 4 → $80/мес (~36,000 ₸)
• У каждого свой аккаунт, свои GPTs
• Нельзя расшарить данные между GPTs
• GPT сына и GPT отца — отдельные вселенные
```

#### Tengu — вся семья/команда:
```
• Одна установка на одном компьютере
• Каждый член семьи = свой агент
• Агенты изолированы (Тимур не видит бизнес-данные)
• Но можно расшарить: общий агент для семейного 
  планирования, в котором видна информация от всех
• Стоимость: $0-15/мес на ВСЕХ
```

```toml
# Один Tengu — несколько пользователей
[[routing]]
pipe = "telegram"
sender = "@erzhan_boss"     # папа
agent = "erzhan"

[[routing]]
pipe = "telegram"  
sender = "@timur_2011"      # сын
agent = "timur"

[[routing]]
pipe = "telegram"
sender = "@aigul_teacher"   # мама
agent = "aigul"
```

### 5. 🔒 Приватность

#### Custom GPTs:
- 🔴 Данные хранятся на серверах OpenAI (США)
- 🔴 По умолчанию OpenAI **может использовать ваши данные** для обучения моделей
- 🔴 Можно отключить (Settings → Data Controls), но файлы всё равно на их серверах
- 🔴 Подчиняется законам США — правительство может запросить данные
- 🔴 Загруженные файлы остаются у OpenAI даже после удаления GPT

#### Tengu:
- 🟢 Данные на вашем компьютере
- 🟢 При использовании Ollama → **ничего не уходит в сеть**
- 🟢 При использовании API → данные не для обучения (см. политику Anthropic)
- 🟢 Подчиняется вашим собственным правилам
- 🟢 Удалили файл = удалено навсегда

**Для бизнеса в Казахстане это критично:**
```
Custom GPT: зарплаты ваших сотрудников 
хранятся на сервере в Вирджинии, США.

Tengu + Ollama: зарплаты хранятся в файле 
на компьютере в вашем офисе в Караганде.
```

### 7. 🧩 Навыки и расширения

#### Custom GPTs — Actions:
```
Чтобы подключить API:
1. Написать OpenAPI-спецификацию (JSON/YAML)
2. Настроить аутентификацию (OAuth2 или API key)
3. Пройти модерацию OpenAI
4. Ограничено: только HTTP-запросы
5. Нельзя: работать с файлами, запускать скрипты
```

Пример: чтобы GPT мог проверять остатки на складе, нужно:
- Поднять REST API для вашего склада
- Написать OpenAPI-спэку
- Настроить в GPT Builder
- **Это работа программиста на несколько дней**

#### Tengu — Skills (навыки):
```markdown
Чтобы научить Tengu проверять остатки:

Создайте файл skills/warehouse/SKILL.md:

---
name: warehouse-check
description: Проверка остатков на складе
---

Когда пользователь спрашивает про остатки:
1. Открой файл data/warehouse/stock.csv
2. Найди нужную позицию
3. Покажи количество и дату последнего поступления
4. Если остаток < 10 — предупреди
```

**Это обычный текстовый файл. Написать может любой.**

## 🧪 Разница на реальном примере

### Задача: «Веди учёт рейсов моей логистической компании»

#### Custom GPT:
```
Шаг 1: Создать GPT «Логист-помощник»
Шаг 2: Написать инструкцию (промт)
Шаг 3: Загрузить Excel с рейсами

❌ Проблемы:
• Excel устаревает через час — нужно перезагружать
• GPT не может ЗАПИСАТЬ новый рейс — только советует
• История теряется после закрытия чата
• Нет доступа из Telegram
• $20/мес за одного диспетчера

Результат: «умный советчик», 
который читает вашу устаревшую таблицу.
```

#### Tengu:
```
Шаг 1: Установить Tengu (одна команда)
Шаг 2: Настроить агента в config.toml
Шаг 3: Написать в Telegram

✅ Результат:
• Саня диктует голосовое → рейс создан
• Данные записываются в файлы автоматически
• Ничего не теряется — всё на диске
• Работает из Telegram
• $0-5/мес на всю компанию

Результат: «цифровой диспетчер», 
который ведёт ваш бизнес в реальном времени.
```
