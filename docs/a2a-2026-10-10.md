# A2A — agents talk to other agent harnesses (2026-10-10)

A2A = the Agent2Agent protocol (spec **1.0.1**, `a2aproject/A2A`, Linux
Foundation). tengu speaks it both ways, per sandbox config:

| Direction | What | How |
|---|---|---|
| tengu → other harness | an agent calls a remote agent | opt-in tool `a2a` + `[a2a.remotes.<name>]` |
| other harness → tengu | a remote client calls tengu's planner / agents | `tengu a2a serve --sandbox <s>` + `[a2a.server]` |
| operator | look / test from a shell | `tengu a2a card\|send\|get\|cancel\|cards\|remotes` |

Wire support: JSON-RPC 1.0 (native) and 0.3 (both directions); the
client also calls HTTP+JSON 1.0. gRPC: no. Push notifications: no (the
card says so; the methods answer `PushNotificationNotSupported`).

## 1. Call another harness (client)

```toml
# sandboxes/<s>/config.toml
[a2a.remotes.research]                       # name: [a-z0-9][a-z0-9_-]*
url = "https://agents.example.com/research"  # base URL (card at /.well-known/agent-card.json) or the card URL
bearer_env = "RESEARCH_A2A_TOKEN"            # or: header = "X-API-Key" + header_env = "…"
description = "The research team's harness."
# endpoint_url = "…"                         # call here instead of the card's URL (container address, other host)
# timeout_secs = 120                         # longest wait for a task; max_result_chars = 12000

[default_scopes.a2a]                         # or [agents.<a>.scopes.a2a]
net_hosts = ["agents.example.com"]
env_reads = ["RESEARCH_A2A_TOKEN"]

[agents.analyst]
tools = ["a2a", "read_file"]                 # opt-in
```

| `a2a` action | Args | Result |
|---|---|---|
| `list` | — | the remotes (no request) |
| `card` | `remote` | name, interface used, capabilities, auth, skills |
| `send` | `remote`, `message` and / or `data` (JSON text), `task_id` + `context_id` to continue, `wait_secs` | task (state, artifacts, `next:` hint) or reply message |
| `get` / `cancel` | `remote`, `task_id` (`wait_secs`) | the task |

| Rule | Value |
|---|---|
| Interface | the card's first one tengu speaks: JSON-RPC 1.x / 0.3, HTTP+JSON 1.x |
| Hosts | only `url` / `endpoint_url` hosts are called — a card naming another host is refused (credential never leaves) |
| Gate | `[egress]` (Tor by default; a loopback remote goes direct) + scope `net_hosts` per request; credential var via `env_reads` |
| Wait | `returnImmediately`, then `GetTask` 0.5 s → 5 s until settled or `wait_secs` |
| Ids | JSON-RPC ids 1, 2, …; `messageId` = the tool call id (a retry = the same message) |
| Audit | one `egress.jsonl` line per request: `tool = "a2a"`, `remote`, `op`, `host`, `status`, `ms` |
| Engines | openrouter, local, claude_code (MCP bridge) — the same code; all three tested (§ 4) |

Planner routing needs no Rust: give a routable agent the tool and a
`description` ("talks to the research harness over A2A") — the planner
picks it like any agent.

## 2. Serve tengu to other harnesses (server)

```toml
[a2a.server]
token_env = "TENGU_A2A_TOKEN"   # clients send Authorization: Bearer <it>
orchestrator = true             # the planner at /a2a (root card)
agents = ["researcher"]         # each at /a2a/agents/<name> (needs a description)
# bind = "127.0.0.1"  port = 8710  public_url = "https://tengu.example.com"
# max_tasks = 500  max_running = 4  run_timeout_secs = 900  context_turns = 8
# allow_unauthenticated = true  # loopback bind only, never hardened
```

```
TENGU_A2A_TOKEN=$(openssl rand -hex 24) tengu a2a serve --sandbox <s>
curl http://127.0.0.1:8710/.well-known/agent-card.json
```

| Route | Answer |
|---|---|
| `GET /.well-known/agent-card.json` | root card (planner, else first agent); `A2A-Version: 0.3` / `?A2A-Version=0.3` → 0.3 form |
| `GET /a2a[/agents/<n>]/.well-known/agent-card.json` · `…/agent.json` | that endpoint's card (v1 · 0.3) |
| `POST /a2a` · `POST /a2a/agents/<n>` | JSON-RPC; SSE for `SendStreamingMessage` / `SubscribeToTask` |

| Method | Behaviour |
|---|---|
| `SendMessage` | new task → run → `COMPLETED` + one `text/plain` artifact `response` (or `FAILED` + reason); blocking unless `returnImmediately` |
| `SendStreamingMessage` / `SubscribeToTask` | task, `artifactUpdate`, `statusUpdate` until settled |
| `GetTask` · `ListTasks` · `CancelTask` | `historyLength`, paging (`o<n>` tokens), cancel kills the run |
| push configs · `GetExtendedAgentCard` | `-32003` · `-32004` (capabilities false) |

| Rule | Value |
|---|---|
| Who answers | planner endpoint: one-shot orchestrator turn, session `a2a-<contextId>`; agent endpoint: one in-process turn with the agent's tools / scopes / engine |
| Context | `contextId` kept; last `context_turns` completed turns go to the next turn |
| Parts in | text, data (fenced JSON), text-like `raw`; file URLs / binary → `ContentTypeNotSupported` |
| Out | answer + error text redacted (vault values, `*_TOKEN`… env) |
| Versions | `A2A-Version` 1.x · 0.3 · absent (method name decides); other → `-32009` |
| Safety | fail-closed auth; private agents (no `description`) never served; no lease (no loops / feeds / exec tools), may run beside `tengu run` |
| State | in memory; a restart forgets tasks |
