The seven layers

Click any layer to expand its mechanism list. Top-down ordering matches the per-turn execution path (Layer 1 first, then 2, then 3…).

There is no LLM-driven summariser anywhere in the harness. Every "summary" is either truncated concatenation (Layer 1 #4, Layer 3 #15) or written by the model as a tool call (Layer 5 #21). The closest thing tengu has to Claude Code's /compact is the combo of Layer 1 #4 (replaces older messages with a synthetic summary message) plus Layer 3 #15 (rewrites prior-round tool results to first-line-only mid-loop).

What tengu does NOT have

Comparison points for future sessions and design discussions.

Missing context-management features

  • No LLM-driven auto-summarise pass. Every "summary" in the harness is either truncated concatenation (maybe_compact_flow, compact_tool_result) or written by the model itself as a tool call (compress_and_store). There is no in-harness LLM call whose only job is to compress prior context.
  • No /compact slash command in the TUI.
  • No semantic dedupe of repeated tool calls. Two identical http_request calls keep both full responses.
  • No retrieval over prior turns of the current session for the chat loop. With postgres_memory, planner-side opt-in recall reads Postgres agentic_memory; otherwise planner memory lanes are empty.
  • Subagent step traces are NEVER fed back into the planner's history. Only the final summary survives. postgres_memory writes Postgres agentic_memory; legacy vector builds keep old compatibility.
  • Claude Code engine has zero in-loop compaction. Layer 4's max_mcp_result_chars is the only governor on that path. If a Claude Code subagent fans out a lot of tool calls, Claude's own context fills up — the harness can only cap individual results, not compact prior ones.
  • No per-skill dedup. If two skills duplicate content (e.g. shared boilerplate), both go in the system prompt at full size up to max_skill_context_tokens.
  • No sliding window over planner memory. cross_plan_top_k is a top-K, not a recency-weighted window.
