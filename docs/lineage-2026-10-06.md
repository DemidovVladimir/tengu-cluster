# Lineage — experiments, variants, Experience, capabilities, generations (2026-10-06)

`TENGU_ROADMAP.md` P0–P5 as built: the foundation that lets Tengu prove whether its next generation (W2) is better than the current one (W1). Product intent: `TENGU_HANDOFF.md`. Review package: [`w1-review-2026-10-06.md`](w1-review-2026-10-06.md).

| Rule | Applied as |
|---|---|
| Reuse → extend → new | xlab run dirs, `report.json`, the paper ledger, the recorder day files and the rule W / paper-fill domain code are read, never rebuilt |
| Evidence immutability | `tengu evidence snapshot` copies evidence into a read-only vault; the originals are never opened read-write |
| Missing facts | the string `"UNKNOWN"`, never a guess |
| Plug and play | one record = one TOML file under `lineage/`; a new record needs no Rust |
| Hard enforcement | a sandbox bound to a generation cannot load, list or run a capability outside it (§ 4) |
| Surfaces | CLI only (`tengu lineage`, `tengu evidence`); no new tool until Phase 6+ (rule R1 cost, roadmap: retrieval is not connected to decisions yet) |

## 1. Records — `lineage/`

| Dir | Record | Phase |
|---|---|---|
| `evidence/<id>.toml` | evidence snapshot: vault items + sha256 + provenance | P0 |
| `incidents/<id>.toml` | operational / data incident | P0 · P4 |
| `generations/<id>.toml` + `locks.toml` | generation manifest (W1 …), freeze locks, preregistration seals | P1 · P5 |
| `experiments/<id>.toml` | hypothesis → configuration → evidence → result → verdict | P2 |
| `families/<id>.toml` · `variants/<id>.toml` | hypothesis family · one variant (spec or hand analysis) | P3 |
| `episodes/<id>.toml` | Experience episode | P4 |
| `capabilities/<id>.toml` | decision-relevant capability | P5 |

Ids `^[A-Za-z0-9][A-Za-z0-9._-]{0,79}$`; the file stem is the id. Every record: `id`, `title` (≤ 160 chars), optional `notes`. Every table `deny_unknown_fields`.

| Value | TOML | Rule |
|---|---|---|
| `Time` | `"2026-10-01T18:28:09Z"` · `"2026-09-30"` (day) · `"UNKNOWN"` | compares known values only; a day = [00:00, 24:00) UTC |
| `Count` | `27` · `"UNKNOWN"` (+ `precision = "EXACT" \| "APPROX" \| "LOWER_BOUND"`) | |
| `EvidenceClass` | `DEVELOPMENT HOLDOUT FORWARD_PAPER LIVE_MICRO LIVE_PRODUCTION NONE` | handoff § 26; `NONE` = docs, code, config |
| `Provenance` | `LIVE_RECORDED BACKFILLED MISSING NOT_APPLICABLE DERIVED REPORTED` | `DERIVED` = recomputable by tengu; `REPORTED` = a figure in a doc whose raw inputs are gone |
| `Integrity` | `CLEAN CONTAMINATED UNKNOWN` | of a window (e.g. a time holdout the hypothesis-forming study already saw) |

| Locator | Resolves to |
|---|---|
| `repo:<path>` | a repo file |
| `run:<state>/<run id>[/<file>]` | `<TENGU_HOME>/state/<state>/backtests/<run id>/<file \| report.json>`, else `keep-<run id>`, else its vault copy |
| `vault:<snapshot>/<path>` | `<TENGU_HOME>/state/evidence/<vault>/<path>` (read-only copy, § 3) |
| `state:<state>/<path>` | a live state file — mutable: verify warns `mutable_evidence` |
| `git:<40 hex>` · `record:<kind>/<id>` · `url:<https>` | a commit · another record · external (never resolved) |

`[[evidence]]` on any record: `ref` (locator), `role`, `class`, `provenance`, optional `sha256`, `note`.

| Validation (`tengu lineage verify`) | Error |
|---|---|
| a reference names a record that does not exist | `dangling_ref` |
| an episode's information is unknown-timed or after its decision; `decided_at` UNKNOWN; `context.as_of` after the decision; `action.executed_at` before it | `future_leakage` |
| a HOLDOUT result without a HOLDOUT window; DEVELOPMENT and HOLDOUT overlapping in time without `split_by = "INSTRUMENTS"` | `holdout_missing` · `holdout_overlaps_development` |
| a CLEAN HOLDOUT overlapping a DEVELOPMENT window of another experiment of the family that ran not after it (Warn under `split_by = "INSTRUMENTS"`: scopes are text) · a CLEAN HOLDOUT / DEVELOPMENT window with an UNKNOWN bound (Warn) | `holdout_seen_before` · `window_unknown` |
| a FORWARD_PAPER experiment without a FORWARD window (with known bounds), a `validity`, FORWARD_PAPER evidence, or with every FORWARD_PAPER result's evidence UNKNOWN | `forward_incomplete` |
| a FROZEN generation whose manifest or a capability record it lists differs from its lock; a seal that does not match | `frozen_manifest_changed` · `seal_mismatch` |
| `--pins`: a pin recomputes differently; a binding names no tool / kind; a sandbox a FROZEN / ACTIVE generation lists without `[generation] id = <it>` resolving to this registry | `pin_drift` · `unknown_binding` · `sandbox_unbound` |
| `--evidence`: a file missing or its sha256 differs; a `extract`ed result differs from its source (± 0.05 bps, ± 0.005 USD) | `evidence_missing` · `evidence_mismatch` · `result_mismatch` |

| Pin target | sha256 of |
|---|---|
| `config:<sandbox>/<dotted path>` | canonical JSON (`domain/canonical.rs`) of that value of `sandboxes/<sandbox>/config.toml` |
| `spec:<sandbox>/<strategy>` | the normalized spec = a run's `spec_sha256` |
| `tool_schema:<tool>` | canonical JSON of the catalog tool's input schema |
| `skill:<name>` · `repo:<path>` | the file's bytes |

## 3. Evidence (P0)

| Command | Does |
|---|---|
| `tengu evidence snapshot --record lineage/evidence/<id>.toml` | copies each item's `source` into `<TENGU_HOME>/state/evidence/<vault>/<path>` (refuses an existing vault or a filled record; a SQLite FILE whose non-empty `-wal` is not itself an item, or a DIR holding a non-empty `*-wal` — checkpoint first; an item path `MANIFEST.json` or two paths equal ignoring case), sha256 per file (a dir: tree hash = sha256 of sorted `"<sha256>  <relpath>\n"` lines), `chmod a-w`, writes `MANIFEST.json`, fills the record |
| `tengu evidence verify <id>` | re-hashes the vault: MATCH · MISMATCH · ABSENT (an empty DIR item present: MATCH, the empty tree hash) |
| `tengu evidence coverage` | minute coverage of recorded rows per stream (recorder day files, read-only) and gaps → MISSING, or BACKFILLED where `market.db` holds the bars |
| `tengu evidence grade --ledger <vault ledger.db>` | per account: trades, gross, fees, funding, slippage, net, bps; 12 checks — cash / fills / funding reconciliation, each funding row's `qty` = the fills' size at its hour (`funding_qty`), every held hour booked or owed (`funding_hours`); risk verdicts; the PIT check of the decision rows |
| `tengu evidence regrade` | rule W or a variant re-graded from recorded books (`hl_book/1` walk, `domain/xm/paper.rs`) — the Saturday prereg and an independent check of the paper fills. Universe default = every `mkt_ctx/1` key at the anchor or the signal (a selected name without a book is MISSING, never replaced); `--signal-at` after `--entry` refused unless `--allow-signal-after-entry` (then `LOOK-AHEAD: …`, JSON `look_ahead`); `--compare-ledger` takes the trades opened in [entry, exit] |
| `tengu evidence evaluate <run dir>` | Phase 6 (2026-10-08): a gated backtest run (live or its vault copy) → one row per candidate; rules · Jev · HOLD scored on the same candidates, per candidate and per trade, calibration, latency, cost; Jev `PROVEN` only when it beats rules and HOLD per candidate, `REJECTED` only when its takes lose money (`domain/backtest/evaluation.rs`) |

## 4. Generation binding (P5)

```toml
[generation]               # in sandboxes/<name>/config.toml
id = "W1"
registry = "../../lineage" # relative to this file
```

| Point | Rule |
|---|---|
| `Config::load` (every surface) | the registry loads; the generation lists this sandbox; every tool an agent, feed or loop uses that a capability binds is in the generation; an opt-in tool (`WORKSPACE_TOOLS`) no capability binds is refused; every `[backtest.strategies]` kind is available |
| `backtest` (tool + CLI) | an inline / `--spec` kind outside the generation → `capability_unavailable` (`--fetch`: before anything is fetched) |
| executor build | a tool outside the generation is not registered (defense in depth) — in-process and in `tengu mcp-bridge` (not listed either; its default-`main` fallback keeps the loaded config's generation) |
| `tengu lineage verify --pins` | every pin recomputes; FROZEN manifests (+ their listed capability records) match their locks; every sandbox a FROZEN / ACTIVE generation lists binds it (`sandbox_unbound`) |
| Docker | `make up SANDBOX=<s>` mounts the file at `/opt/tengu/sandboxes/<s>/config.toml` (`TENGU_CONTAINER_CONFIG` → `TENGU_CONFIG`): the name is detected, `../../lineage` → `/opt/tengu/lineage` |

## 6. As built — where the code differs from §§ 1–5

| Point | As built |
|---|---|
| Ids | unique across **all** kinds (`show` / `trace` take a bare id; `<kind>/<id>` also accepted): a reuse is `duplicate_id` (Error) |
| Extra codes | `invalid_id`, `invalid_field` (shapes), `inconsistent_ref` (a variant of another family), `capability_version_missing`, `binding_conflict`, `load_error` (loader, per file) · `--pins`: `pin_unresolved` (also every `contract`, `cost_pin`, model `where`; a library variant's `spec_sha256` recomputes or `pin_drift`) · `--evidence`: `extract_unsupported` (Warn: no `ResultSource` reads that `extract`; sources: `arm:` / `gate` from `report.json`, `ledger:<account>` from a vault ledger — `outbound/lineage/ledger.rs`), `evidence_planned` (Info: an evidence record not captured yet) |
| `future_leakage` · `seal_mismatch` · `holdout_seen_before` | Warn, not Error, when only day precision makes the order undecidable (same day; equal values are not) |
| Locks | the **last** `[[frozen]]` row of a generation must match `Registry::frozen_digest` (its file + every capability record it lists) whatever its status (a status change after freezing needs a new row); W1's row was recomputed once for this definition (2026-10-06, review fixes, before the branch merged: `a64c505f5ac99e3ed25f63cca31513de273771c9a5467287eda06007f2e74a43`, `frozen_at` / `commit` kept); `tengu lineage seal` refuses a record already sealed, one not `preregistered = true`, one whose first outcome is past, or UNKNOWN (a variant with no experiment yet seals) |
| Review fixes (2026-10-06) | majors #1–#10 and minors #11, #14, #16, #18, #19, #21–#23 of the branch review — each with a regression test named after its scenario |
| `UNKNOWN` | allowed for any locator field and for reference fields (also `NONE`); `Time` must be UTC |
| `run:` | falls back to the vault copy an evidence record holds as a DIR item ending `<state>/backtests/<run id>` (or `keep-<run id>`) |
| `extract` | `arm:<name>[/in_sample\|/holdout]` compares n, mean, both CI ends, net USD, `t_stat` (± 0.005); `gate` = jev − rules: n = `gate.decided`, mean / CI = `gate.diff_ci` |
| Search accounting | `UNREGISTERED` in `family` = run hashes no variant carries whose `strategy` name is one of the family's (library variants' or its matched runs'); `attempts` lists every run |
| Pins | `config:` / `spec:` read the raw sandbox file (no `${VAR}` substitution); `spec:` = `domain/backtest/spec.rs::spec_sha256` (moved from the use case, hashes unchanged — tested on the xlab library) |
| `[generation]` at load | fails on: registry load errors, the generation absent or not listing the sandbox, an Error finding on that generation's record or any `binding_conflict` (other registry findings are `verify`'s), tool / kind refusals, a FROZEN generation's `config:` / `spec:` drift — the loading sandbox's pins from the raw text just loaded, another sandbox's from `<registry parent>/sandboxes/<s>/config.toml`; kinds are closed-world like opt-in tools |
| Evidence readers | `open_read_only` (immutable) refuses a database with a non-empty `<db>-wal` ("live or uncheckpointed WAL: snapshot / checkpoint first"); the W1 vault holds only empty `-wal` files |
| Grade funding checks | the size at hour h = after the fills before h (the ledger settles before a fill); flat then and opened on h = after the fills at h; an open trade's hours are required up to its last settled hour (no "now" in a ledger) |
| CLI | `tengu lineage` runs before any config / secret load (registry only) |
| Registry dir | `lineage/` holds the W1 records (115 files), SOE-G0 (`CANDIDATE`, unlocked: its generation, three tool capabilities, the `soe` family — `docs/soe-2026-10-08.md` § 13) + `locks.toml`; `sandboxes/xlab` and `xmarket-weekend` are bound to W1, `sandboxes/soe` to SOE-G0 |
