§3 Distill — author a skill from a conversation

Agent (with skill_distill in workspace_tools) synthesizes a full SKILL.md from its in-context understanding. Tool writes files atomically — no LLM call inside the tool. 

sequenceDiagram
    actor U as User
    participant A as LLM Agent
    participant E as engine/collect_engine_response
    participant T as SkillDistillTool
    participant F as fixtures::extract_fixtures
    participant FS as Filesystem

    U->>A: "save this as a skill called eth-balance"
    A->>A: synthesize body + metrics
    A->>E: tool_call skill_distill(...)
    E->>T: execute(&call, &messages)
    T->>T: scope.check_fs_write
    T->>T: validate_name
    T->>T: collision check (3 tiers)
    T->>F: extract_fixtures(slice)
    F-->>T: Vec (args schema-redacted)
    T->>FS: write tmp/ + atomic rename
    T-->>E: { path, fixtures_created,
loaded_in_current_conversation: false }
    E-->>A: tool result
    A-->>U: "Saved. Available next session."
Cache-discipline invariant: the new skill does NOT activate in the current conversation. The runtime's ToolRegistry is fixed per session — the distilled skill becomes callable on the next tengu chat start.

§4 Eval — score the skill

Replays evals/prompts.yaml through the configured agent. Each row is scored by (a) the pre-existing row LLM judge AND (b) any metrics: declared in SKILL.md frontmatter. Writes rolling metrics.json + appends history.jsonl. 

sequenceDiagram
    actor U as User
    participant CLI
    participant EB as eval_builder::run
    participant D as discover_skills
load_skill_metrics
    participant R as run_row
    participant A as Agent (fixture-runner)
    participant RJ as Row judge
    participant MK as MetricKind::run
    participant JC as EvalJudgeClient
    participant S as storage::finalize_run

    U->>CLI: tengu eval skill-creator
    CLI->>EB: EvalArgs { no_persist, max_per_run_reports, ... }
    EB->>EB: prune_old_run_dirs (evals/runs/)
    EB->>D: discover_skills + load frontmatter metrics
    D-->>EB: SkillUnderTest + Vec<MetricSpec>
    loop each fixture row
        EB->>R: run_row(persist_transcript)
        R->>A: dispatch prompt
        A-->>R: assistant text + tool outcomes
        R->>RJ: judge_row(expected, obs, text)
        RJ-->>R: Verdict (pass / fail)
        loop each frontmatter metric
            R->>MK: run(spec, fixture, ctx)
            alt kind = llm_judge
                MK->>JC: judge(user, prefill="")
                JC-->>MK: extract_json_object
            else deterministic
                MK->>MK: shell / tool / script
            end
            MK-->>R: MetricOutcome
        end
        R-->>EB: RowResult + metric_outcomes
    end
    alt persist
        EB->>S: finalize_run(samples, rolling_window,
max_per_run_reports)
        S->>S: write report.json
        S->>S: append history.jsonl
        S->>S: recompute metrics.json
        S->>S: prune metrics/runs/ to N most recent
    end
    EB-->>CLI: SkillReport + exit code
ExitMeaningTypical cause
0All gated metrics passSkill is healthy
1At least one gated metric failedCandidate for tengu skill-evolve
2Runner errorConfig missing, LLM unavailable, broken fixture file

§5 Evolve — improve a gated metric

Bounded rewrite → rescore loop. Scratch git worktree isolates cycles. Best-cycle selection enforces "no regression greater than 0.05 absolute on non-target gated metrics." User approves before any change touches the real SKILL.md.

State machine — every decision the loop makes 
stateDiagram-v2
    [*] --> Sweep
    Sweep --> Baseline: sweep_stale_worktrees
(older than 24h)
    Baseline --> PickTarget: run_skill (real workspace)
    PickTarget --> NothingToEvolve: no gated metric
(exit 0)
    PickTarget --> CreateScratch: lowest gated pass_rate

    CreateScratch --> Cycle1: git worktree add
or non-git fallback

    state "Cycle 1..N" as C {
        Cycle1 --> CallImprover
        CallImprover --> ApplyProposal: ChatServiceFactory::run_turn
        ApplyProposal --> Rescore: atomic rename SKILL.md
        Rescore --> Decide: run_skill (scratch)
        Decide --> Cycle1: continue
        Decide --> EarlyExit: target = 1.0 OR
all gated pass AND
target improved ≥ 0.15
    }

    EarlyExit --> PickBest
    Cycle1 --> PickBest: max_cycles reached

    PickBest --> AllRegressed: no cycle passes
regression tolerance
    PickBest --> ApprovalGate: candidate found

    AllRegressed --> [*]: Worktree preserved
for inspection

    ApprovalGate --> Apply: [y]
    ApprovalGate --> Discard: [n]
    ApprovalGate --> Details: [d]
    ApprovalGate --> OpenWT: [o]

    Apply --> SanityRerun: copy scratch SKILL.md
append evolve_log.md
    SanityRerun --> Remove: git worktree remove
    Discard --> Remove
    Details --> Remove
    OpenWT --> [*]: scratch preserved

    Remove --> [*]

sequenceDiagram
    actor U as User
    participant CLI
    participant EV as run_evolve
    participant SW as sweep_stale_worktrees

    participant CS as ChatServiceFactory

    participant AG as approval_gate

    U->>CLI: tengu skill-evolve skill-creator --max-cycles 1
    CLI->>EV: EvolveArgs
    EV->>SW: sweep stale worktrees (>24h)
    EV->>EB: baseline run_skill
    EB-->>EV: metrics.json
    EV->>EV: pick_target_metric
    EV->>FS: create scratch worktree
    loop cycle 1..N
        EV->>EV: build improver user msg
        EV->>CS: run_turn(improver_agent, msg)
        CS->>IM: LLM call
        IM-->>CS: JSON proposal
        CS-->>EV: ImproverProposal
        EV->>FS: atomic rename SKILL.md in scratch
        EV->>EB: cycle run_skill (scratch)
        EB-->>EV: scratch metrics.json
    end
    EV->>EV: pick_best (filter regressions > 0.05)
    alt candidate found
        EV->>AG: render GateView
        AG->>U: diff + delta + [y/n/d/o]
        U->>AG: keystroke
        AG-->>EV: Decision
        alt Apply
            EV->>FS: copy scratch SKILL.md to real
            EV->>EB: sanity re-eval on real
            EV->>FS: git worktree remove
            EV-->>U: "Changes applied."
        else Discard
            EV->>FS: git worktree remove
            EV-->>U: "Baseline preserved."
        end
    else all regressed
        EV-->>U: "No changes. Worktree preserved."
    end

§7 Filesystem layout

After a full distill → eval → evolve cycle for my-skill:

skills/
  my-skill/
    SKILL.md                    # frontmatter: name, description, metrics: [...]
    evals/
      config.toml               # per-skill eval agent config
      prompts.yaml              # flat list: [{id, prompt, expected}, ...]
    metrics/
      <rubric_name>.md            # llm_judge rubric
      history.jsonl             # append-only (one line per run per metric)
      evolve_log.md             # append-only (one line per evolve attempt)
      runs/<ts>/
        report.json             # capped at N by max_per_run_reports
    metrics.json                # rolling snapshot, overwritten each run

evals/runs/<ts>/                # global eval runs — capped by --keep-runs
  report.json
  my-skill-f1.md

.tengu/
  worktrees/evolve-my-skill-<ts>/  # scratch git worktree (swept at startup)
  scratch/evolve-my-skill-<ts>/    # non-git fallback

Failure modes

What's missingSymptom
[skill_lifecycle] block "[skill_lifecycle] config missing; needed for tengu skill evolve"
[agents.skill-improver] Improver dispatch fails — "snapshots lock poisoned"
"skill_distill" not in agent's workspace_tools Agent describes the call in prose — never actually invokes the tool
skill_distill missing from validator allowlist "unknown tool 'skill_distill'" at config load
SkillLifecyclePlugin not registered in build_tool_executor "Tool 'skill_distill' is not available to this agent" at call time

§9 Worked example — eth-balance-check

User builds a wallet-balance workflow, distills it, evaluates, evolves.

① Conversation

User: check balance of 0xcaD88677...
Agent: [http_request → POST eth.llamarpc.com]
       [hex_to_uint256 0x1bc16d674ec80000]
       [persistent_store set last_balance_0xcaD88]
       "2.0 ETH. Saved."
User: save this as eth-balance-check

② Agent's distill call

skill_distill(
  name: "eth-balance-check",
  description: "Use when checking ETH balance
     of a wallet on mainnet...",
  body_markdown: "## Overview\n...",
  metrics: [
    { kind: "shell_check",
      name: "eth_balance_format", ... },
    { kind: "llm_judge",
      name: "procedure_quality", ... }
  ],
  from_message_index: 0
)

③ Files written (atomic)

skills/eth-balance-check/
  SKILL.md                      # frontmatter + body + metrics block
  evals/prompts.yaml            # 1 fixture, tool args schema-redacted
  metrics/procedure_quality.md  # rubric stub (user fills in)

④ Evaluate

$ tengu eval eth-balance-check

eth-balance-check (1 row, 35s)
  ✓ f1    pass    procedure_quality: gated (0.65 < 0.70)

1/1 passed. Exit 1 (gated metric fails rolling threshold).

⑤ Evolve

$ echo "n" | tengu skill-evolve eth-balance-check --max-cycles 2

Target: procedure_quality (0.65 → 0.88, delta +0.23)

SKILL.md changes:
  @@ ## Procedure @@
  +1. **Pre-flight: confirm chain_id.** Before signing...
   2. Fetch raw balance via eth_getBalance (latest)
  +3. Verify result is non-empty hex (0x + ≥1 char)
   4. Convert wei → ETH via hex_to_uint256

[y] apply, [n] discard, ...
Known gap: skill_distill does NOT generate evals/config.toml. Users must write it by hand before tengu eval can run against a distilled skill — see skills/skill-creator/evals/config.toml for a template.
