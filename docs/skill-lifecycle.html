◆ Skill Lifecycle Subsystem

From conversation to evolving skill

Agents author skills mid-chat via skill_distill. Declared metrics score each fixture. Bounded rewrite-rescore loops improve gated metrics behind a user approval gate.

3 · Eval

Replay fixtures → score metrics

Per-row: dispatch the agent, let the row-judge verdict pass/fail, then score every metrics: entry declared in SKILL.md frontmatter. Four kinds of checks:

sh
shell_check
Runs a command, matches exit code + stdout regex. For deterministic outcomes — tx confirmed, file exists.
metric_kinds/shell_check.rs
ai
llm_judge
Loads a rubric_file. A judge LLM scores the fixture transcript against narrative criteria.
metric_kinds/llm_judge.rs
ta
tool_assertion
Dispatches a workspace tool. Asserts via value_matches / value_equals / value_in.
metric_kinds/tool_assertion.rs
//
script
Invokes sh <path> with fixture data as env vars. Parses stdout JSON. Escape hatch for custom checks.
metric_kinds/script.rs

Runner flow

①

Discover skill + load metrics

discover_skills(["skill-creator"], roots) finds SKILL.md. load_skill_metrics parses frontmatter metrics: block.

②

Prune old evals/runs/

Before writing this run, prune_old_run_dirs removes the oldest — retention cap default 10 via --keep-runs.

③

Per-row: dispatch + row-judge + metric kinds

For each fixture in prompts.yaml: dispatch prompt through configured agent; judge passes/fails the row; each metric kind scores against the transcript. When --no-persist, skip transcript write.

④

Finalize — if persist

finalize_run writes metrics/runs/<ts>/report.json, appends history.jsonl, recomputes rolling metrics.json, prunes old per-skill run dirs.

⑤

Exit code

0 all gated metrics pass · 1 at least one gated metric failed (candidate for evolve) · 2 runner error (config, LLM unavailable, fixture malformed).

4 · Evolve

Bounded rewrite-rescore loop

Picks the lowest gated metric as target. Creates a scratch git worktree. Dispatches the skill-improver agent through ChatServiceFactory::run_turn for up to N cycles. Best-cycle selection filters regressions > 0.05 on non-target gated metrics. User approves before anything touches the real SKILL.md.

The loop

0

Startup sweep

sweep_stale_worktrees removes any .tengu/worktrees/ dirs older than worktree_stale_hours (default 24h). Catches leaks from prior crashes / Ctrl-C.

1

Baseline eval

Full run_skill on the real workspace. Reads back metrics.json. pick_target_metric selects the lowest gated metric.

2

Scratch worktree

git worktree add .tengu/worktrees/evolve-<skill>-<ts>. Non-git workspaces fall back to .tengu/scratch/ with a copy of skills/<skill>/.

3

Cycle 1..N: improver proposes

Build user message: current SKILL.md body + failing fixture transcripts + prior-cycle summaries. Call ChatServiceFactory::run_turn(improver_agent, msg). Parse {"proposal":{"body_markdown":...,"rationale":...}}.

4

Apply + rescore inside scratch

apply_proposal_to_skill_md atomic rename. run_skill scoped to scratch. Early exit if target hits 1.0 OR all gated pass + target improved ≥0.15.

5

Best-cycle selection

pick_best: filter cycles that regress any non-target gated metric by more than 0.05. Among survivors, pick highest target pass_rate, tie-break by fewer body lines added.

6

Approval gate

Terminal renders baseline→best delta, unified diff of SKILL.md, improver's rationale. User presses one key:

User decision

y
Apply
Copy scratch SKILL.md to real. Sanity re-eval. Worktree removed. evolve_log.md logs "accepted".
n
Discard
Worktree removed. Baseline preserved. evolve_log.md logs "rejected".
d
Details
Prints full proposal JSON. Then auto-discards. Worktree removed.
o
Open worktree
Prints worktree path. Leaves it in place. User inspects manually; re-run to retry.
⚠ All-cycles-regress path
If every cycle regresses some non-target gated metric beyond tolerance, pick_best returns None. Evolve exits without prompting: "No changes applied. Worktree preserved for inspection." Worktree auto-cleans on next evolve if older than 24h.

6 · Example

eth-balance-check — end to end

User builds a wallet-balance checker. Asks the agent to save it. Evaluates. Evolves.

① Conversation
User
Check the balance of 0xcaD88677CA87… on Ethereum mainnet.
Agent (tool)
http_request → POST https://eth.llamarpc.com
result: "0x1bc16d674ec80000"
Agent (tool)
hex_to_uint256 → "2000000000000000000"
Agent (tool)
persistent_store set last_balance_0xcaD88 → ok
Agent
2.0 ETH. Saved to persistent store.
User
Let's save this as a skill called eth-balance-check.
② Agent invokes skill_distill
skill_distill(
  name: "eth-balance-check",
  description: "Use when checking ETH
     balance of a wallet on
     mainnet via public RPC.",
  body_markdown: "## Overview\n…",
  metrics: [
    { kind: "shell_check",
      name: "balance_format",
      cmd: "…",
      min_pass_rate: 0.9 },
    { kind: "llm_judge",
      name: "procedure_quality",
      rubric_file: "metrics/…md",
      min_pass_rate: 0.7 }
  ],
  from_message_index: 0
)
③ Files written (atomic)
# skills/eth-balance-check/
├── SKILL.md
│   # frontmatter + body + metrics
├── evals/
│   └── prompts.yaml
│       # 1 fixture, tool args
│       # schema-redacted
└── metrics/
    └── procedure_quality.md
        # rubric stub — user fills in
④ Eval output
$ tengu eval eth-balance-check

eth-balance-check (1 row, 35s)
  ✓ f1    pass

procedure_quality: gated
  0.65 < 0.70   → candidate for evolve

# exit code 1
⑤ Evolve proposal
$ echo "n" | tengu skill evolve eth-balance-check --max-cycles 2

Target: procedure_quality (baseline 0.65 → best 0.88, delta +0.23)

SKILL.md changes:
  @@ ## Procedure @@
  + 1. Pre-flight: confirm chain_id (mainnet = 1).
    2. Fetch raw balance via eth_getBalance ("latest")
  + 3. Verify result is non-empty hex (0x + ≥1 char)
    4. Convert wei → ETH via hex_to_uint256

Rationale:
  Adds pre-flight chain_id check + hex validation.
  Failing fixture f1 accepted empty hex; this traps it.

[y] apply, [n] discard, [d] show details, [o] open worktree:
Known gap
skill_distill does not seed evals/config.toml — the user writes it by hand before tengu eval can run. Template lives at skills/skill-creator/evals/config.toml.
