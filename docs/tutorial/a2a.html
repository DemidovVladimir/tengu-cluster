A2A: other harnesses

Tengu speaks the Agent2Agent protocol both ways. An agent with the a2a tool calls a remote agent the sandbox names. tengu a2a serve lets other harnesses call Tengu's planner or chosen agents.

  • spec 1.0.1 · JSON-RPC 1.0 + 0.3
  • server port 8710 · bearer token
  • remote wait 120 s · result ≤ 12 000 chars
  • run ≤ 900 s · 4 at once
  • 心 heart agents
  • 手 hands tool, server
  • 守 guard egress, auth, scopes
  • data cards, tasks

    What a task can be
    
Task states Tengu writes

  

  
    
    
  • SUBMITTEDstored, waitingThe task exists; it waits for one of the max_running slots.
    • 
    
  • WORKINGrunningThe planner or the agent is on it.
    • 
    
  • COMPLETEDansweredOne text/plain artifact response. The turn joins its context's memory (last 8).
    • 
    
  • FAILEDerror or timeoutThe reason, redacted, is the status message. Runs stop at 900 s; a server stop fails open tasks.
    • 
    
  • CANCELEDstopped by the clientCancelTask aborts the run and its child processes.
    • 
  






  

    Enforced in code
    
Guarantees

  

  
    
    
  • Only named remotes. The tool takes a remote name, never a URL; unknown names list the real ones.
    • 
    
  • Pinned hosts. Requests and credentials go only to the configured remote's hosts; a card cannot redirect them.
    • 
    
  • One egress path. Every call passes [egress] (Tor by default; a loopback peer goes direct) and the tool's net_hosts; the credential variable needs env_reads. One egress.jsonl line per request.
    • 
    
  • Fail-closed server. No token_env and no loopback allow_unauthenticated: the config does not load. An unset token stops the start.
    • 
    
  • No private agents. Only agents with a description can be served; tasks of one endpoint are invisible to another.
    • 
    
  • Redacted out. Answers and errors pass the secret registry before they leave.
    • 
    
  • Same tool on every engine. OpenRouter, local and Claude Code (through the MCP bridge) run the same code; bridge_conformance and the engine matrix prove it.
    •
