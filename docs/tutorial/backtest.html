Backtests

A pure engine replays a strategy spec over market.db: decisions as of each instant, fills at bar closes, then fees, spread and funding. Spec in, run dir out. Tests prove no later bar changes an earlier decision.

In-sample, holdout, and who sees what

Thirty example weekends, --split time:<t>: decisions at or after t are the holdout. The Architect's backtest tool hides it unless asked, and counts every read. The CLI shows both halves and counts its read too.

Six kinds, never code

What a spec can say

Each kind has its own fields and bounds. Names below are xlab's library (sandboxes/xlab).

weekend_window

Rule W on any calendar: s = ln(entry / anchor), fade or follow, optional top_n. weekend_fade, weekend_fade_top4. Optional labels: each name NEWS / UNCERTAIN / NOISE from what was published in [anchor − 240 min, decision]; skip drops a class before top_n (label_skipped). weekend_fade_noise_only in sandboxes/xlab-w2. Optional stop_loss_bps: leave at the first 1h close that far against the trade. Optional rank_by = "net_of_cost": rank top_n by |s| minus the round-trip cost.

daily_window

Anchor, entry, exit as local HH:MM. xyz_overnight_follow: 16:00 → 20:00 → 09:00 New York.

move_trigger

|move over a lookback| ≥ threshold, optional volume ratio, hold / TP / SL. crypto_move_fade: 4 bars, 300 bps.

funding_carry

Take the side funding pays when APR ≥ min; exit below exit_apr_pct or after hold_hours. xyz_funding_carry.

pair_spread

z of ln(a / b) over a lookback: enter at |z| ≥ entry_z, leave at ≤ exit_z. sol_eth_spread.

event_window

Listed events (instrument, t): enter after a delay, exit after N minutes or at a local time.

The gate arm and its cache

The real decision loop (see Decision loop), replayed. Same history in, same verdicts out.

# tengu backtest --gate [<loop>]   (no value = [backtest] gate; xlab: xl_gate)
clock      SimClock set to each candidate's decided_at_ms
loop       terminal actions only: take · skip · ask_architect   # a tool action is refused
history    0   # forced: a request is a function of its candidate alone
cache      <state dir>/backtests/decision-cache.db
key        sha256 of canonical {"model","state","questions"}   # 64 hex chars, never cut
arms       rules (every decided candidate) · jev (the taken ones), + capped twins
limits     --max-decisions 500 (rest counted as cut) · --concurrency 4 (1–16)
--offline  cache only: a miss is a class-error decision, est. cost 0
cost       misses × $0.00004 a decision
# <state dir>/backtests/<run id>/    run id = <YYYYMMDDTHHMMSSZ>-<strategy>, taken ⇒ -2, -3 …
report.json          # the report = row backtest/1:<run id>; + generation, instruments_sha256, costs_sha256
report.md            # the same, readable
trades-<arm>.jsonl   # one trade per line: legs, fills, costs, funding, exit reason
candidates.jsonl     # side, signal, decided / data-as-of, exit plan, features
skips.json           # every skip, drop and [risk] refusal
decisions.jsonl      # with --gate: one audit line per decision, by seq
# beside the run dirs:
decision-cache.db    # never pruned
holdout-reads.jsonl  # append-only ledger of holdout reads (tool and CLI)

Enforced in code

Guarantees

  • No look-ahead. A candidate with data_asof_ms > decided_at_ms is dropped (future_data). Tests scale, delete or cut every bar after t; nothing decided, admitted or closed by t changes.
  • Labels never read the future. An event counts only when published at or before the decision; one at exactly t counts. NOISE needs one covered source span over the whole window, else UNCERTAIN. A spec without labels keeps its spec_sha256. The Jev gate never sees the label.
  • Prices only at a close. The bar ending exactly at the instant; missing ⇒ a skip, never interpolated.
  • Simple return. Gross = side × (exit / entry − 1) × 10⁴, never ln.
  • No peeking at exits. Capped admissions read the book as of the decision, never whether a later bar exists.
  • Read-only warehouse. A run never writes market.db.
  • Reruns match. The bootstrap is seeded; replay loops keep no history and the cache answers by full sha256, whatever --concurrency. Every report records data_through_ms, the newest row it read; --data-through with it reruns on the same data after market.db grew.
  • Runs say what they compare on. Every report records its cohort identity: the bound generation, instruments_sha256 of the ids read and costs_sha256 of each id's resolved cost. [backtest.costs] sits outside spec_sha256; a strategy ranking compares runs on both.
  • Cited runs stay. Retention past keep_runs never deletes a run a lineage registry cites ([generation] or [strategy_ranking]) or a published ranking's latest.json names, and does not count it.
  • The holdout is never shown unrecorded. The tool refuses its text if the ledger line cannot be written.
  • Runaway specs stop early. Past max_candidates a run stops before any arm or file.
  • Only the generation's kinds. In a sandbox bound by [generation], a spec kind no capability of that generation binds is refused before any read, --fetch included: capability_unavailable (Lineage and generations).
Try it

Run the library

From the repo root. --gate online needs OPENROUTER_API_KEY; --offline needs none.

$ tengu backtest --sandbox xlab --strategy weekend_fade --split time:2026-07-01
# arms research + capped, in-sample vs holdout side by side, then the run dir; stderr: holdout read #n for this spec (one ledger line)
$ tengu backtest --sandbox xlab --strategy weekend_fade --data-through 2026-10-05T14:00:00Z
# example bound: only rows known then; stderr: data through … — rerun on the same data: --data-through <ms>
$ tengu backtest --sandbox xlab --strategy weekend_fade_top4 --fetch
# backfills bars + funding first (as tengu history backfill), then runs
$ tengu backtest --sandbox xlab --strategy weekend_fade --gate --max-decisions 200
# gate lines: take / skip counts, cache hits / misses, jev − rules
$ tengu backtest --sandbox xlab --strategy weekend_fade --gate --max-decisions 200 --offline
# same verdicts from decision-cache.db, est. cost 0
$ tengu backtest --sandbox xlab --spec ./big_move_fade.json --format json > report.json
