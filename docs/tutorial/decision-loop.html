Decision loop

An Architect plans; Jev executes. Jev, TypeSafe's typed decision model, reads the analysis map, takes one step of the execution map at a time, and Tengu's tools do the work. It never writes text or tool JSON.

  • model ~typesafe/jev-latest
  • acts at confidence ≥ 0.8
  • ≤ 4 steps per event
  • dry_run on by default
  • 心 heart Architect / planner LLM
  • 決 Jev typed choice
  • 手 hands tools, TOML actions
  • 守 guard checks and gates
  • data stores and logs

    Slots
    
    Jev picks labels; code holds the values
    
    
    A slot fills one tool argument. Three ways, each read from the code's own sources, never typed by the model.
    
  
    
  
    
    
    
      
    Pick from a list
    
      
    pool_1 → 5rCf1DM8LjKTw4YqhnoLcngyZYeNnQqztScTogYHAS6
    
      
    Items from an earlier step of this event, a world row or the event get short labels. Jev answers pool_1; the address stays in code.
    
    
    
    
    
      
    Static list, capped
    
      
    0.5123
    
      
    With caps = { size_sol = 2.0 }, 3 is never offered; the chosen value is checked again before the tool runs.
    
    
    
    
    
      
    Bound: one value

    No question. Missing, empty or over the cap means no value, so the step is not legal. A binding never invents a value.

[decision_loops.lp_exec.actions.plan_swap.slots]

wallet_sol = { observation = "snap", path = "/data/wallet_balances/native_sol/value" }

[decision_loops.lp_exec.actions.swap.slots]
amount = { from = "plan_swap", path = "/swaps/0/amount" }            # bound from an earlier step

    Seven outcomes
    
    What a step can end as
    
  
    
  
      
    
    • runexecutedThe tool ran; ok or failed is in history. A failure halts a sequence.
      • 
    
    • riskrefusedThe tool's [risk] gate said no. History records a failure; a sequence halts.
      • 
    
    • logdry_runA write while dry_run = true: logged, the loop goes on. Steps bound to its output stay illegal.
      • 
    
    • endstoppedA terminal action (no tool), such as hold or done.
      • 
    
    • askescalatedBelow act_at. The planner gets the full state when the surface has one; otherwise the event stops.
      • 
    
    • norejectedMissing answer, a label that was not offered, or a value over its cap.
      • 
    
    • errerrorThe decisions call failed. Audited, then the error propagates.
      • 
  
    

    


    
  
    
    When Jev is down
    
    Retry once, then a 30-second breaker
    
  
    
  
    
    
    429 / 5xxone retry after 0.5–1 s; Retry-After honoured up to 5 s
    
    
    timeout · 4xxno retry: a timed-out call may already be billed
    
    
    fail ×3three failed calls in a row
    
    
    circuit open30 s of instant failures, no request sent
    
    
    trial callsuccess closes it; a failure re-opens it
    
  
    

    


    
  
    
    Enforced in code
    
    Guarantees
    
  
    
  
      
    
    • The TOML is the ceiling. A map cannot add a tool, argument, wallet, mode, slot source or world row; looser caps, more steps, a lower act_at or dry_run off are refused.
      • 
    
    • Every loop can stop. Validation refuses a loop without a terminal action, a sequenced terminal action, or max_steps not above the sequence length.
      • 
    
    • No invented values. A bound slot that reads nothing, or a value above its cap, keeps the step illegal.
      • 
    
    • Old data is never offered. Slots from earlier steps read only this event's history.
      • 
    
    • Tools keep their fences. A loop runs tools as its agent, with that agent's scopes and egress.
      • 
    
    • Audit lines never interleave. Each line is one write_all on an append-only file, across loops and processes.
      • 
    
    • Replay is the same loop. Backtests run it terminal-only on a simulated clock, every answer cached (Backtests).
      •
