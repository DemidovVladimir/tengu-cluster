Engines

Each agent names one engine. OpenRouter and local servers answer over HTTP and Tengu runs the tools; Claude Code and Codex run as CLI subprocesses on your Claude or ChatGPT subscription and reach Tengu's tools through the MCP bridge.

  • engine = openrouter · local · claude_code · codex
  • window 1 000 000 by default; claude_code, codex 200 000
  • local result ≤ 1/8 of the window
  • HTTP call 600 s · CLI idle 120 s
  • 心 heart engine
  • 手 hands tools
  • 守 guard limits
  • data endpoints

    Seven outcomes
    
How an engine call ends

  

  
    
    
  • okeventsText, tool calls, usage, then Done. The tool loop goes on.
    • 
    
  • httpstatus errorOpenRouter error 429: … or Local LLM error …: the body is shown.
    • 
    
  • downunreachableLocal LLM at … unreachable (is the server running?)
    • 
    
  • emptyempty twiceOpenRouter retried once and still got nothing: chat shows nothing, a run-agent step fails.
    • 
    
  • idleCLI idleNo CLI output for 120 s (stream_event_timeout_secs): Claude CLI idle timeout or Codex CLI idle timeout, process killed.
    • 
    
  • captool capMax tool rounds exceeded (71 calls, limit 70), process killed.
    • 
    
  • donestep storedcompress_and_store succeeded in a step: the CLI is stopped on purpose, usage kept.
    • 
  






  

    Enforced in code
    
Guarantees

  

  
    
    
  • No silent default engine. engine must be one of four (config::ENGINES); an empty model or unknown builtin_tools_profile fails the load.
    • 
    
  • Hardened sandboxes run Claude Code bare. With [risk] or a Solana signer, every claude_code agent needs builtin_tools_profile = "none", or load fails.
    • 
    
  • No Codex in a hardened sandbox. With [risk], [soe] or a Solana signer, an engine = "codex" agent fails the load: its built-in shell ignores Tengu scopes.
    • 
    
  • Codex bills the subscription. OPENAI_API_KEY and every CODEX_* but CODEX_HOME / CODEX_CA_CERTIFICATE are removed from the CLI's env; ~/.codex/config.toml is not loaded.
    • 
    
  • The CLI sees only the Tengu bridge. --strict-mcp-config on every run: the operator's own MCP servers never load.
    • 
    
  • Built-in Bash never bypasses the proxy. Under an egress proxy, editor_shell launches as editor.
    • 
    
  • No secret in the temp MCP config. It holds names and paths; the bridge inherits values from the env.
    • 
    
  • Local stays local. The local client ignores every proxy, env ones included.
    • 
    
  • Claude Code's tool count is capped. One call past max_tool_rounds kills the CLI with an error.
    •
