Forward evidence

Grade a forward run from the files it wrote. tengu evidence freezes them into a hashed, read-only vault, then verifies the vault, maps recorder gaps, grades the paper ledger and replays rule W from the recorded books.

  • book ≤ 60 s from the instant (default)

What a record says

Two labels on every item

Class says where a figure sits between development and live money. Provenance says how the bytes came to exist. Both are fixed sets in domain/evidence.rs.

Evidence class

DEVELOPMENT · HOLDOUT · FORWARD_PAPER · LIVE_MICRO · LIVE_PRODUCTION · NONE for docs, code and config, which are not market observations.

Provenance

LIVE_RECORDED while it happened · BACKFILLED later from an archive or API · MISSING never recorded · NOT_APPLICABLE · DERIVED computed by tengu, rerunnable · REPORTED a figure in a doc whose inputs are gone.

Try it: punch holes in a recorder

Coverage: live, backfilled, missing

The example from the coverage test: ten 1-minute slots (example instants), three keys. A slot counts only if a key has an ok or partial row in it. Toggle the second source and the gaps.

  • recorded (ok / partial)
  • gap, a 1m bar exists (0 = no trade)
  • gap, no bar
  • rows, none ok (absent)

    
A sweep gap is a run of slots no key covers: the recorder wrote nothing. A key gap is one key missing while others were recorded. A gap is BACKFILLED for a key only if every gap minute has a bar; a 0-trade bar is counted flat, a stale price. Use --bars for price streams such as mkt_ctx/1, never for books.

  






  

    Try it: break a tiny ledger
    
Grade: twelve checks that must all pass

    
The test ledger: short 2 @ 10, one funding hour received 0.002, cover 2 @ 9. Net 1.983 USD, 991.5 bps of its 20 USD entry (example values). Pick one fault; the lights are what the code reports.

  

  

    

    

    

    
A trade runs from flat to flat per instrument, in (ts_ms, id) order; a flip closes one trade and opens the next, its fee split by quantity. Net = realized − fees − funding paid; bps of the filled entry notional. No closed trade ⇒ mean_net_bps is MISSING, not 0.

  






  

    Try it: move the signal instant
    
Regrade: rule W from the books it saw

    
The independent check of the paper fills, and the grader of rules nobody traded (a preregistration). Example instants; read windows use the CLI defaults.

  

  

    

      
      
      
    

    

    

    

  

  

    
Price at T
The latest mkt_ctx/1 row at or before T, within its max age; mid, else mark. A failed row or no price ⇒ MISSING with the reason.

    
Signal, selection
s = ln(Psignal / Panchor) in bps; 0 is flat. --top-n: largest |s| ≥ --min-abs-signal-bps, ties by id. Fade = −sign(s), follow = sign(s).

    
Entry, exit
Walk --notional-usd into the recorded book; thin depth fills less. The exit walks the entry quantity back; short of it ⇒ MISSING.

    
Fees
--taker-fee-bps F per side, or --fees recorded: the row's taker_fee_bps at entry and exit. One of the two is required.

    
Funding
Each hour entry < h ≤ exit: the recorded funding_1h × oracle, else market.db's rate × the 1m close ending at h, else MISSING.

    
Cross-checks
--compare-ledger: per name vs the ledger trade opened in [entry, exit]. --expect-signals: prices equal to 1e-9, s within 0.05 bps.

  






  

    Phase 6 · decision evaluation
    
Evaluate: rules, Jev and HOLD on the same candidates

    
One row per candidate of a gated backtest run, joined by seq. Each policy is scored on the same candidates: rules take all, Jev takes what it calls take, HOLD takes none. Below: W1's gate run 20261001T182905Z-weekend_fade, read from its vault copy.

Common set
Rows with an outcome (the research trade's net bps) and an answered Jev call. A failed call or a candidate with no trade is left out of all three.

    
Two lenses
Per candidate: what each policy earned across all candidates, skips count 0. Per trade: how good Jev's picks are; this is the gate's own jev − rules, reproduced.

    
Verdict
PROVEN only when Jev beats rules and HOLD per candidate (95 % CI above 0). REJECTED only when its takes lose money. Everything else stays UNPROVEN; W1's Jev is UNPROVEN.

  






  

    Verdicts and exit codes
    
What a command can report

  

  
    
    
  • okMATCHsha256 and bytes as recorded; an item also by its file count.
    • 
    
  • diffMISMATCHSame path, other hash or size.
    • 
    
  • goneABSENTIn the manifest or the record, not in the vault.
    • 
    
  • newEXTRAIn the vault, not in the manifest. Every item can match and verify still fails.
    • 
    
  • n/aMISSINGgrade / regrade: no source for a value. Printed with the reason, never counted as 0.
    • 
    
  • flagLOOK-AHEADregrade's line 1 (JSON look_ahead) when an allowed signal follows the entry.
    • 
    
  • 0exit 0verify all MATCH, grade all PASS; coverage and regrade printed their report.
    • 
    
  • 1exit 1Not MATCH, a FAIL, or a refusal: vault exists, record captured, live WAL, bad instants.

    Enforced in code
    
Guarantees

  

  
    
    
  • Originals are only read. Every SQLite file opens immutable=1, read-only: no -wal or -shm created, no migration, no retention sweep.
    • 
    
  • A live WAL is refused. A database with a non-empty -wal beside it is not read. Snapshot copies one only when its -wal is an item too; a dir holding one is refused.
    • 
    
  • All or nothing. Every source is checked before the vault dir exists; one bad source creates nothing.
    • 
    
  • Created once. An existing vault, or a record that already holds captured_at or a hash, is refused.
    • 
    
  • A copy is its source. Each file is hashed before and after the copy; never copied over an existing vault file.
    • 
    
  • Sealed. chmod a-w on every file and dir; MANIFEST.json is created new and never lists itself.
    • 
    
  • No silent look-ahead. A signal after the entry is refused unless allowed, then flagged on line 1.
    • 
    
  • No substitutes. A selected name without a usable book stays a MISSING leg; the next name is not graded in its place.
    • 
    
  • Nothing else runs. No config, no LLM, no network. Ids and hashes are printed in full.
    •
