From public history to one warehouse

Try it: how far back can you go?

5 000 bars, whatever the interval

Hyperliquid keeps the newest 5 000 bars per interval, the open one included, so 4 999 closed bars reach back. Pick an interval and a start.

What a stored bar means

Three rules every reader keeps

Open bar dropped

A bar still open at fetch time is never stored. Gecko's newest bar and HL's last one are dropped the same way.

No trades: a flat bar

Hyperliquid keeps a no-trade hour as a flat bar at the last close, n = 0. A spec's min_entry_trades skips it (thin_entry).

Splits adjusted on read

[backtest.splits] (xlab: hyperliquid:xyz:KIOXIA 3-for-1 at 2026-09-28T08:00:00Z). Earlier prices ÷ ratio; a straddling bar is dropped. market.db keeps raw bars.

The warehouse

Three tables, one file per state dir

WAL SQLite in <TENGU_HOME>/state/<xmarket.state>/, outside every workspace. Every row names its source.

-- src/adapters/outbound/market_data.rs
CREATE TABLE bars (
  instrument TEXT, interval TEXT, t_open_ms INTEGER,   -- key
  o REAL, h REAL, l REAL, c REAL, v REAL,
  n INTEGER,                                           -- trades, nullable (Gecko has none)
  source TEXT, fetched_at_ms INTEGER,
  PRIMARY KEY (instrument, interval, t_open_ms)) WITHOUT ROWID;
CREATE TABLE funding (
  instrument TEXT, t_ms INTEGER,                       -- key
  rate_1h REAL,                                        -- HL per hour; > 0 = longs pay
  premium REAL, source TEXT, fetched_at_ms INTEGER,
  PRIMARY KEY (instrument, t_ms)) WITHOUT ROWID;
CREATE TABLE ctx (                                    -- HL archive asset contexts
  instrument TEXT, t_ms INTEGER,                       -- key
  mark REAL, oracle REAL, mid REAL, impact_bid REAL, impact_ask REAL,
  oi REAL, day_ntl_vlm REAL, funding_1h REAL, premium REAL, source TEXT,
  PRIMARY KEY (instrument, t_ms)) WITHOUT ROWID;
# source values
hl                       # Hyperliquid mainnet
hl:<host>                # any other host (testnet): never mistaken for mainnet
gecko:<network>:<pool>   # GeckoTerminal pool, full pool address
hl-archive:asset_ctxs    # HL S3 archive import
json:<file name>         # JSON import without its own source
The Architect's reader

market_history: one window, one row

Row mkt_history/1:<instrument>:<interval>, ttl 0: never cached. Window default: the 7 days before to; at most 100 000 bars; 48 sampled points (1–200).

Numbers (too few rows ⇒ left out, never 0)

ret_bps
ln(last / first close) × 10⁴, ≥ 2 bars
vol_bps
sample sd of log returns × 10⁴, ≥ 3 bars
max_drawdown_bps
deepest fall from a running peak close
avg_volume
mean bar volume (HL base size, Gecko USD)
funding_mean_apr_pct
mean rate_1h × 24 × 365 × 100
gaps
grid slots with no stored bar
  • okokBars in the window, nothing failed.
  • partpartialBars in the window, but a fetch failed.
  • noneabsentNo bar stored in the window, nothing failed.
  • errerrorNo bar, and a fetch or the store read failed.
Enforced in code

Guarantees

  • Only closed bars are stored. Every fetcher and importer drops a bar still open at its time.
  • A bad row writes nothing. The decoder names the row; its page (or the whole JSON file) is not written.
  • Every request is fenced. Egress policy, the client's host and the budget, on every request; a denial sends nothing.
  • No future at t. Readers take prices through close_at / observable_at: a bar closing after t is invisible at t.
  • Mainnet stays mainnet. Rows from another HL host are tagged hl:<host>.
  • Agents cannot touch the file. market.db sits in the state dir, outside every fs root and workspace.
  • Reads stay offline. Without fetch / --fetch no request is sent, and a missing market.db is an error, never created by a backtest.
