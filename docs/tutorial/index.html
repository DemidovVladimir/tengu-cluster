Tengu field manual

A multi-agent harness in one Rust binary. You type a message; a planner picks agents; each agent works in its own process with its own tools; memory keeps what matters. One page per feature, every page drawn from the code.

  • 1 binary, Rust only
  • 1 TOML file per team
  • 3 engines: OpenRouter, local, Claude Code
  • network through Tor by default
The doctrine

Heart, brain, hands

Every diagram in this manual uses these three colours for these three jobs.

心Heart = the LLM

The planner only emits plan JSON. Subagent models think and call tools.

脳Brain = memory

Open Brain holds live memory; the LLM Wiki holds reviewed knowledge.

手Hands = tools

Files, HTTP, wallets, market data. Each call checks its scope first.
