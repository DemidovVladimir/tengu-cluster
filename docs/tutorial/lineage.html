Lineage and generations

Every idea, variant, run, verdict, decision and incident is one TOML record under lineage/. tengu lineage checks how they link and what was known when. A frozen generation pins its parts; a bound sandbox refuses to load if one drifts.

Eight kinds, one TOML file each

What the registry holds

Counts are the repo's lineage/ today. The file stem is the id; ids are unique across all kinds, so show and trace take a bare id.

families/ · 15

Family

One idea: hypothesis, role (primary, negative control, placebo), status, [prior_search]. Links preceded_by and controls.

variants/ · 41

Variant

family, parent (or ROOT), [[changed]] dims, preregistered, exactly one [spec] shape.

experiments/ · 30

Experiment

kind, [[windows]], [[results]] with evidence and extract, [verdict], validity. Links family, variant, generation, capabilities, incidents.

episodes/ · 3

Episode

Context, information with available_at, alternatives (one chosen), decision, action, outcome, [quality], a lesson.

incidents/ · 8

Incident

class, start and end, strategy_impact, [[data_impact]]: each gap MISSING, BACKFILLED or LIVE_RECORDED.

capabilities/ · 20

Capability

Class, version, permission, lifecycle, a contract pin target, bindings: tool:<name> or strategy_kind:<kind>.

generations/ · 2

Generation

W1 (frozen) and SOE-G0 (candidate, unlocked): status, sandboxes, [[capabilities]] id, version, decision and research policy, models, [[pins]].

evidence/ · 1

Evidence

A read-only vault snapshot: items with sha256. See Forward evidence.

Values. A missing fact is the string "UNKNOWN", never a guess. Times are quoted UTC: an instant "2026-10-04T22:00:00Z" or a day "2026-09-30". Evidence is a locator: repo:, run:, vault:, state:, git: (40 hex), record:<kind>/<id> or url:. locks.toml holds one [[frozen]] row (W1) and no [[sealed]] row yet.

    Preregistration
    
Seal it before the outcome

    
A record with preregistered = true is sealed: tengu lineage seal appends its file digest and the time to locks.toml. The digest hashes the values (TOML → canonical JSON), so comments and layout do not count.

  

  

    

      
      
      
      
    

    
# lineage/variants/<id>.toml has preregistered = true; <id> is a placeholder
$ tengu lineage seal variant:<id>

[[sealed]]
record = "variant:<id>"
sha256 = "<64 hex: the file's digest>"
sealed_at = "<now, UTC, whole seconds>"
# stderr: sealed variant:<id> into lineage/locks.toml

# refused, nothing written:
variant:<id> is already sealed in lineage/locks.toml — a seal is never redone
variant `<id>` is not preregistered = true — set it before sealing
variant/<id> has errors — fix them before sealing:
variant/<id>: its first outcome (<t>) is already past — a seal now is not a preregistration
variant/<id>: its first outcome is UNKNOWN (a FORWARD window start or a ran_at not given) — a seal cannot be shown to precede it; record the start first
# a variant with no experiment yet has no outcome: it seals

    
# a value of the sealed file changed afterwards: verify row (severity, code, record, message)
ERROR  seal_mismatch  variant/<id>  sealed <sha256 in the row> at <sealed_at>; the file now hashes <sha256 now>
# a new comment or a re-ordered table: same digest, no finding

    
# first outcome: an experiment's ran_at; a FORWARD_PAPER one's FORWARD window start;
# a variant's: the earliest of its experiments'
ERROR  seal_mismatch  experiment/<id>  sealed at <t>, after its first outcome <outcome>: not a preregistration
WARN   seal_mismatch  experiment/<id>  sealed <day> vs first outcome <day>: not provably before — give instants

    
# preregistered before the registry existed: an [[evidence]] with role = "prereg" instead
# lineage/experiments/fwd.rule_w.2026-10-02.toml (class, provenance, note left out)
[[evidence]]
ref = "vault:w1-2026-10-06/ext/binaries/tengu-6fcb455"
role = "prereg"
sha256 = "e2c3bb8f88f25d4a6a9275200b7b248ac8a052db16e344fb674da4e208320c72"
# neither a seal nor such a ref: Error
ERROR  seal_mismatch  experiment/<id>  preregistered, but neither sealed (`tengu lineage seal experiment:<id>`) nor carrying an [[evidence]] with role = "prereg"

    What verify can say
    
The codes verify can return

    
Each finding is one row: severity, code, record, message. Any Error exits 1. Filter by the pass that runs it.

    Enforced in code
    
Guarantees

  

  
    
    
  • Strict records. Every table denies unknown fields; the file stem must equal id; another dir or file is refused. Each load error names its file.
    • 
    
  • Nothing guessed. UNKNOWN compares to nothing, and an unknown decision time or information time is an Error.
    • 
    
  • Luck is visible. Decision quality and outcome are separate fields; the quadrant is computed from them on every read.
    • 
    
  • A freeze holds. The last [[frozen]] row must equal the digest of the generation file plus every capability file it lists, even one edited at the same version.
    • 
    
  • Bound means bound. Config::load refuses an unlisted sandbox, a tool, feed, loop action or strategy kind outside the generation, and a drifted config: / spec: pin of a FROZEN one.
    • 
    
  • Closed world for opt-ins. An opt-in tool that no capability binds is refused under any generation; base tools stay.
    • 
    
  • Defense in depth. The executor build and the MCP bridge drop a tool outside the generation; a backtest refuses an outside kind before any read (Backtests).
    • 
    
  • Cited runs stay. A bound sandbox's run-dir retention ([backtest] keep_runs) never deletes a run the registry cites (run:<state>/<run id>), and does not count it.
    • 
    
  • A seal is never redone. seal refuses a record already sealed, not preregistered, with errors, or whose first outcome is past or unknown.
    • 
    
  • Read-only views. Only seal writes: one row appended to locks.toml. The adapters never write a registry, vault, run dir or state file.
    •
