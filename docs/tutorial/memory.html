Open Brain and LLM Wiki

Open Brain is live agent memory in Postgres with pgvector: user messages, step summaries and captures. The planner recalls from it. Promoted memories compile into the LLM Wiki: one cited Markdown page.

The agentic_memory tool and its tables

Opt-in per agent (workspace_tools). Replies below are the code's own shapes; values in angle brackets are placeholders.

capture

Stores content as one event, embedded (text only without a key). kind defaults to event.

captured: event_id=<uuid> kind=<kind> bytes=<n>

recall

Events and chunks. Vector order first, full text if no vector hit. top_k 5, kept in 1–20.

- <uuid> [<kind>] <first line, 500 chars>

ingest_source

content or a workspace path. Raw copy on disk, one source row, chunks with vectors.

ingested: source_id=<uuid> chunks=<n> raw_path=<path>

promote

Marks target_id (an event by default) as stable, with a reason and evidence.

promoted: promotion_id=<uuid> target=<kind>/<id>

compile_wiki

One page per title (default agentic-memory) from the 30 newest promotions.

compiled_wiki: page=<path> items=<n> mode=llm

lint

Counts only: rows per table and wiki pages. No hygiene checks yet.

agentic_memory lint: events=<n> sources=<n> chunks=<n> promotions=<n> wiki_pages=<n>

memory_events

  • id uuid
  • session_id · agent · role · kind
  • content text · summary
  • embedding vector(1536)
  • metadata jsonb · created_at

memory_sources

  • id uuid · kind · uri
  • title · raw_path
  • hash sha256 of the content
  • metadata jsonb · created_at

memory_chunks

  • id uuid
  • source_id → sources, cascade
  • event_id → events, cascade
  • content · embedding vector(1536)
  • metadata · created_at

memory_promotions

  • id uuid
  • target_kind · target_id
  • status default 'pending'
  • reason · evidence jsonb
  • created_at

Indexes: full text (english) on events and chunks, GIN on metadata, HNSW cosine on both embedding columns. The DDL runs once per process under a Postgres advisory lock.

    Five writers
    
Who writes memory_events

  

  
    
    
  • planuser messageEvery plan(), not replan(). kind message, agent planner, role user.
    • 
    
  • stepstep summaryThe compress_and_store text, in-process or through the MCP bridge. kind step_output, agent subagent.
    • 
    
  • backstopfinal replyA step that never called compress_and_store but replied: its text, same kind.
    • 
    
  • hookwebhook outputA webhook turn's final text: step_output, step id webhook-handler.
    • 
    
  • toolcaptureAny kind. session and agent from the args, else the exported env, else the model slug. Embedded when a key is set.
    • 
  






  

    Enforced in code
    
Guarantees

  

  
    
    
  • Read before write. The cross-session lane runs before the current message is stored, and drops rows whose text equals it.
    • 
    
  • Memory never breaks a turn. A lane that fails becomes an empty block; a failed write is a warning. The planner still plans.
    • 
    
  • No wrong-size vector is stored. Anything but 1536 finite numbers falls back to a text-only row or full-text recall.
    • 
    
  • One session key. The planner and its run-agent children share one session_id, so the this-session lane finds their outputs.
    • 
    
  • Scope first. Every tool call checks that its scope may read TENGU_MEMORY_DATABASE_URL; ingest_source and compile_wiki also need workspace write.
    • 
    
  • No instruction-file pages. compile_wiki refuses titles that become claude.md or agents.md; hardened sandboxes also the five prompt files.
    • 
    
  • Full provenance. An LLM page ends with a ## Sources list of every promoted token, even ones the model left out.
    • 
  






  

    Try it
    
Start Postgres, build, share

    
Open Brain needs no [memory] enabled; that switch is for workspace memory. Put your own credentials in the URL.

  

  


$ docker compose --profile postgres-memory up -d postgres-memory
$ export TENGU_MEMORY_DATABASE_URL=postgres://<user>:<password>@localhost:5432/<db>
$ cargo build --release --features postgres_memory
$ ./target/release/tengu chat --sandbox lping
  # planner turns now write kind=message rows; steps write kind=step_output
$ ./target/release/tengu agentic-memory-server
  # stdio JSON-RPC: initialize · tools/list · tools/call — point any MCP client here
