Anatomy of an agent block

The real xm_architect block from sandboxes/xmarket, plus its private partner. One block is one agent on every surface.

  1. [agents.xm_architect]
  2. default = true
  3. engine = "claude_code"
  4. model = "claude-opus-5-5" # bare slug for claude_code
  5. workspace = "~/xmarket-workspace"
  6. tools = ["read_file", "list_directory", "hl_ctx", "hl_book", "risk_status", "paper_positions"]
  7. description = """Researches Hyperliquid perp markets for the xmarket paper desk … Researches only and never trades."""
  8. example_queries = ["show the paper positions and the risk state", …]
  9. [agents.xm_architect.identity]
  10. name = "xmarket architect"
  11. [agents.xm_architect.limits]
  12. max_tool_rounds = 30 # claude_code counts tool calls
  13. step_timeout_secs = 600
  14. [agents.xm_architect.claude_code]
  15. builtin_tools_profile = "none" # required in a [risk] sandbox
  16.  
  17. [agents.xm_executor] # no description: private
  18. tools = ["hl_ctx", "hl_book", "risk_status", "paper_order", "paper_close", "paper_positions", "xm_exits"]

Defaults copied, never merged

fold_default_scopes copies a [default_scopes.<tool>] entry into an agent only when the agent has no entry for that tool. An agent's own entry replaces the default whole.

Sandbox default

[default_scopes.hl_ctx]
fs_roots  = ["~/xmarket-workspace"]
net_hosts = ["api.hyperliquid.xyz"]
env_reads = ["HL_API_URL"]

Agent has none → copied

# xm_architect.scopes.hl_ctx (after load)
fs_roots  = ["/Users/you/xmarket-workspace"]  # ~ expanded (example home)
net_hosts = ["api.hyperliquid.xyz"]
env_reads = ["HL_API_URL"]

Agent has one → kept as is

# example: an agent's own entry
[agents.a.scopes.hl_ctx]
net_hosts = ["api.hyperliquid.xyz"]
# no fs_roots: denied, not inherited

A configured scope is deny-by-default per field. A tool with no scope at all gets the permissive fallback rooted in the workspace (see Scopes and hardening).

What stops the load

Load errors you will meet

Messages as the code writes them; <…> marks a placeholder.

  • parseunknown fieldA misspelled section such as [rsik], or an old key like max_turns in an agent block.
  • enginemust be one of openrouter|claude_code|localagents.<id>.engine, with the value it got.
  • defaultonly one agent can have default=trueTwo agents claim the chat.
  • opt-inworkspace_tools: unknown toolOnly the opt-in catalog names pass; the message lists them.
  • emptyat least one agent must be configuredA file with no [agents.*] block.
  • hardenedbuiltin_tools_profile = "none"A claude_code agent in a [risk] or signer sandbox without it.
  • hardened[[mcp_servers]] are not allowedAlso: any scope granting shell_bins.
  • loopdecision_loops.<n>.agent: no [agents.<a>] blockA loop names an agent that does not exist.
  • generationtool `<t>` is bound by capability `<c>`, which generation `W1` does not includeAlso: an opt-in tool no capability binds, a sandbox the generation does not list, a drifted frozen pin (Lineage and generations).
Enforced in code

Guarantees

  • No silent typos. Config, AgentConfig and [agents.*.local] deny unknown keys; the load fails.
  • All issues at once. Validation collects every problem into one Config validation failed (N issues) error.
  • No merging. --sandbox replaces the base config whole; an agent's own scope replaces the default whole.
  • A broken base file stops only what needs it. It is loaded before --sandbox; when it fails, chat, telegram, webhooks, run, doctor, decide, history, backtest and risk with --sandbox log a warning and go on; any other command stops.
  • Children see the same file. run-agent reloads it by sandbox name; the bridge reads the absolute TENGU_CONFIG.
  • One set of sections. Every agent holds the same SandboxSections, so tools read identical [risk], [paper], state dir and rate limits.
  • Hardened means hardened. With [risk] or a Solana signer, every agent's fallback scope runs no shell.
  • Bound sandboxes stay in their generation. With [generation], every load checks the sandbox against lineage/generations/<id>.toml; xlab and xmarket-weekend bind W1.
