Secrets and redaction

Keys live in an encrypted vault and reach tools only by name, as env vars. Every tool result, error and reply is scrubbed of known secret values before a model or a person reads it.

    is_env_secret verdicts
    
    How an env var is judged
    
  
    
  
      
    
    • maskcredentialCredential suffix, 8+ chars, not a placeholder or public id: every copy masked.
      • 
    
    • namenot a credential nameHL_API_URL, MAX_TOKENS, bare TOKEN: never registered from the env.
      • 
    
    • shorttoo shortUnder 8 chars, so common words are not cut from every result.
      • 
    
    • fakeplaceholderchangeme, postgres, your…, one repeated char, a number.
      • 
    
    • reftemplate${VAR}, $VAR, <paste your key>: not a value yet.
      • 
    
    • idpublic idAn EVM address under any name; a Solana address, signature or 0x hash under *_TOKEN.
      • 
  
    

    


    
  
    
    Enforced in code
    
    Guarantees
    
  
    
  
      
    
    • Encrypted at rest. AES-256-GCM with a key from PBKDF2-HMAC-SHA256, 600 000 rounds, a fresh 32-byte salt and 12-byte nonce on every write.
      • 
    
    • Owner-only, never half-written. Each write goes to a temp file, is renamed into place and chmod 600; a group- or world-readable vault prints a warning at load.
      • 
    
    • Names, not values. tengu secret list prints keys only; tools read values by $NAME, gated by env_reads.
      • 
    
    • The env wins. A vault value never overrides a var that is already set.
      • 
    
    • Every surface masks. Tool text, typed observations (headline, errors, features, data) and error text pass the same registry.
      • 
    
    • Longest first. Values are replaced longest to shortest, so no fragment of a longer secret survives a shorter match.
      • 
    
    • Public ids stay whole. An EVM address is never registered from the env; under *_TOKEN neither is a Solana address, signature or 0x hash. Key material under other names is.
      • 
  
    
  
    Exact text only. Redaction replaces exact copies of a registered value. A secret that is encoded, split or changed (base64, URL-encoded) is not caught. Env values under 8 chars are not registered; vault values are, whatever their length.
    
  
    Keep provider keys off this machine. With [keys] no OpenRouter, Telegram or RPC key is in the vault or the env at all: each is a secret of a Cloudflare Worker, set by you in Cloudflare; tengu calls <proxy>/<route> and the Worker adds the key (sealed keys). The session token it uses ends in _TOKEN, so it is masked like any other credential; the registry is extended after it is exported, so old .env / vault values stay masked. [keys] strip removes local copies of moved keys at load.
