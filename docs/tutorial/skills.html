Skills

A skill is a folder with a SKILL.md. Tengu finds it in fixed tiers, keeps only the names an agent lists in skill_packages, puts documentation into the prompt and turns shell skills into tools.

  • first folder name wins
  • one body ≤ 16 000 tokens
  • all bodies ≤ 32 000 tokens
  • resource read ≤ 1 MB
  • 心 heart the agent's LLM
  • 手 hands shell skill tools
  • 守 guard filters and checks
  • data folders, prompt, files

Frontmatter the loader reads

Five keys, nothing else

name

Required. Lowercased, - becomes _; letters, digits and _ only. Must not equal a built-in tool.

description

One line. The planner and view_skill list show it.

base_url

Alias homepage. Makes an API skill. Must start with http:// or https:// and hold no ; | & ` $ ( ).

env_vars

A list; NAME? is optional. A missing required one shows as (missing: NAME) in /skills. It does not block loading.

commands

Slash commands. /cmd args in the TUI or Telegram becomes a turn that follows the skill's ## Commands.

Load gate: requires_bins (on PATH), requires_env (set) and os (macos / linux / windows; darwin is macos), inline [a, b] or a block list: a skill missing one is not loaded, and a log line names why. editable_by_learner and metrics are not read by the loader (the writers and evals use them).

Which variables reach the prompt?

A body's $NAME or ${NAME} is replaced only when the name is declared, set, and not secret-shaped. Secret names stay literal; http_request expands them at call time.

    Try it: the prompt budget

    Do my skills fit?

    Real body sizes from skills/, at 4 bytes per token. Tick skills as if they were in skill_packages, then grow your own.

    032 000 tokens

    Each body is cut at 64 000 characters (16 000 tokens) plus [truncated]. A body that would cross 32 000 is dropped with a warning; smaller later ones may still fit. Fragments are added in name order, so the same skills drop every turn.

    At load time

    What can happen to a skill

    • docin the promptA documentation or API body, whole.
    • cuttruncatedLonger than 16 000 tokens: the rest is replaced by [truncated].
    • toola toolA shell skill, for an agent that runs a shell.
    • skipnot listedIts name is not in skill_packages.
    • skipshadowedAn earlier tier has a folder with the same name.
    • badinvalidBad name, a built-in tool's name, or a {{x}} with no parameter. Warned and skipped.
    • nono shellA shell skill in a [risk] or signer sandbox. Warned once, never a tool.
    • dropover budgetWould push the prompt past 32 000 tokens. Warned, left out.
    Enforced in code

    Guarantees

    • Listed or nothing. Every surface loads only names in skill_packages (alias skills); an empty list loads no skill.
    • No shell, no shell skill. An agent with no_shell_fallback (every agent in a [risk] or signer sandbox) never gets a shell skill as a tool.
    • Secrets stay out of the prompt. A variable whose name contains KEY, SECRET, TOKEN, PASSWORD or PASS is never expanded into a skill body.
    • Arguments are quoted. Each string argument is single-quoted into the shell template; the first command word must pass shell_bins.
    • Loading only reads. write_file refuses any path under a skills folder or .tengu/.
    • Locked skills stay locked. manage_skill refuses every write but create on a skill with editable_by_learner: false.
    • No escape from resources/. Reads and writes refuse .. and absolute paths; reads stop at 1 MB; writes refuse .tengu/, .claude/, .git/, CLAUDE.md, AGENTS.md, .mcp.json.
    • Hardened prompt files. In a [risk] or signer sandbox a resource named MEMORY.md, USER.md, IDENTITY.md, PROFILE.md or CONTEXT.md is refused too.
