Three scenarios from one range

An estimate picks its end per scenario

Revenue is better higher, cost is better lower. The downside takes each input's adverse end, the upside its favorable end. An unknown gives no value in any scenario.

Enforced in code

Guarantees

  • No float is money. A TOML or JSON float is refused; 0.10 + 0.20 is exactly 0.30.
  • Nothing is rounded on the way in. A third fraction digit is refused, not rounded.
  • Rounding never flatters. Inflows (revenue, contribution) round down; outflows (cost, exposure, capital) round up, negatives included.
  • No silent conversion. A rate converts only its own base currency; money in two currencies never adds or compares.
  • An unknown currency stays unknown. A source amount outside the closed set becomes UNKNOWN with the reason.
  • Unknown is not zero. No scenario reads a value from an unknown estimate.
  • Versions are explicit. A record tagged with a schema version other than 1 is refused.
