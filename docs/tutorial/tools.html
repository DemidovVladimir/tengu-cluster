    // src/adapters/outbound/tools/workspace/run_command.rs
async fn execute(&self, args: &Value, ctx: &ToolCtx<'_>) -> Result<ToolOutput> {
    let command = require_str(args, "run_command", "command")?;
    let bin = crate::domain::scope::shell_command_binary(command);
    if bin.is_empty() { anyhow::bail!("run_command: empty command"); }
    ctx.scope.check_shell_bin(bin)?;          // the gate: first command word only
    let audit = egress::policy().guard_shell("run_command", command)?;
    let output = ctx.shell.execute_shell(command, ctx.workspace);   // 300 s cap
    audit.finish(&output);
    Ok(ToolOutput::from(output?))
}

    The schema subset

    Every tool definition must fit what OpenRouter models, local servers and Claude all accept. Edit the JSON; the checks are a port of schema_lint.rs.

      In CI the lint runs over every catalog row, compress_and_store, shell-skill tools and MCP proxies. At runtime an external [[mcp_servers]] tool that breaks a rule is dropped with a warning.

      Enforced in code

      Guarantees

      • One row, every surface. Chat, plan steps, loops, tengu tool and the MCP bridge all register through register_catalog.
      • Lists cannot drift. catalog_tests fail when an opt-in row and WORKSPACE_TOOLS disagree.
      • Opt-ins are checked at load. A workspace_tools name outside the 33 fails the config.
      • Every tool gates itself. scope_lint fails a tool whose execute has no scope.check_ in its first 30 lines and no pure-compute note.
      • No tool runs unscoped. A configured entry wins; otherwise the fallback, rooted in the workspace and shell-free in a hardened sandbox.
      • No duplicate names. Registering a second tool with the same name fails that plugin.
      • Secrets stay out. Text, observations and error messages pass SanitizedToolExecutor before a model sees them.
      • Generation-bound. In a sandbox with [generation], a tool outside it is neither advertised nor registered, with a warning, on top of the load-time refusal (Lineage and generations).
